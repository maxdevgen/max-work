## 3. Problém: mikrofon sluchátek Jabra EVOLVE 20 MS nefunguje (2026-09-28)

### Příznak

Sluchátka Jabra EVOLVE 20 MS připojená přes USB — zvuk ve sluchátkách hraje, mikrofon aplikace nesnímají.

### Diagnostika

| Úroveň | Příkaz | Zjištění |
|---|---|---|
| USB | `lsusb` | `0b0e:0300 GN Netcom Jabra EVOLVE 20 MS` — detekováno |
| ALSA | `cat /proc/asound/cards` | karta 2 `USB-Audio - Jabra EVOLVE 20 MS` — ovladač načten |
| ALSA mixer | `amixer -c 2 contents` | `Headset Capture Switch` = on, `Headset Capture Volume` = 8/8 — nic neztlumeno |
| PipeWire | `wpctl status` | výstup (sink) = Jabra, ale **výchozí vstup (source) = Ryzen HD Audio (interní SN6140)** |

`pactl` není nainstalovaný (balíček `pulseaudio-utils`), proto se použil `wpctl` z WirePlumberu.

### Příčina

PipeWire/WirePlumber po připojení sluchátek přepnul na Jabra jen **výstup**, výchozím **mikrofonem** zůstal interní audio vstup počítače. Aplikace tedy poslouchaly špatné zařízení.

### Oprava

```bash
wpctl status                  # najít ID zdroje "Jabra EVOLVE 20 MS Mono"
wpctl set-default <ID>        # v tomto případě ID 63
```

Ověření: 3 s záznam přes `pw-record --target 63` — signál přichází (šum pozadí, peak 134, RMS 4), mikrofon je tedy aktivní a neztlumený. **Ověřeno uživatelem 2026-09-28: mikrofon funguje.**

### Poznámky

- WirePlumber si volbu výchozího zařízení pamatuje i po restartu; po odpojení Jabry se vrátí na interní vstup.
- Chrome běžel už před změnou — je potřeba ho restartovat, nebo zvolit mikrofon ručně v nastavení webu (ikona vlevo od adresy → Mikrofon).
- Pokud je stále ticho: zkontrolovat tlačítko mute na kabelovém ovladači sluchátek (hardwarový mute se softwarově nezruší).
- Grafická kontrola: Nastavení → Zvuk → Vstup → „Jabra EVOLVE 20 MS", indikátor úrovně musí reagovat na řeč.
