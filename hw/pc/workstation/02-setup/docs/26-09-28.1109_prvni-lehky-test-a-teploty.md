# První lehký test a měření teplot — SAPPHIRE Edge AI 370 (2026-09-28)

Cíl: ověřit, že je hardware v pořádku (SSD, CPU, GPU, RAM, chyby v jádře), a změřit teploty v klidu a při **lehké** zátěži. **Není to zátěžový test.**

## Omezení, kvůli kterým je test lehký

| # | Omezení | Dopad na test |
|---|---|---|
| 1 | **Modrá fólie na thermal padu SSD není sundaná** — pad neodvádí teplo z disku | SSD jen krátké a lehké testy, žádný dlouhý zápis; přísný limit teploty SSD |
| 2 | RAM: dočasných 8 GB, z toho 4 GiB bere iGPU → systému zbývá 3.4 GiB, volných ~0.5 GiB, bez swapu | žádný test paměti se zátěží (`stress-ng --vm`), před testem zavřít Chrome a další těžké aplikace |
| 3 | CPU a GPU fólie neovlivňuje (chladí je chladič s ventilátorem) | CPU lze zatížit středně, ale jen krátce — cílem je ověření, ne maximum |

## 5. Lehký test SSD — krátce

Testovací soubor v domovské složce (oddíl `/`, stejný SSD), 1 GB — `/data` patří rootovi. Žádný dlouhý sekvenční zápis (ten disk nejvíc zahřívá a s nesundanou fólií nemá smysl).

```bash
# 5.1 — sekvenční zápis 1 GB jednou (krátký, pár sekund)
fio --name=seqwrite --filename=$HOME/fio-test.bin --size=1G --rw=write --bs=1M --direct=1 \
  --ioengine=libaio --iodepth=8 2>&1 | tee "$OUT/${TS}_test-51-ssd-write.log"

# 5.2 — sekvenční čtení, 20 s
fio --name=seqread --filename=$HOME/fio-test.bin --size=1G --rw=read --bs=1M --direct=1 \
  --ioengine=libaio --iodepth=8 --time_based --runtime=20 2>&1 | tee "$OUT/${TS}_test-52-ssd-read.log"

# 5.3 — náhodné čtení 4K, QD1, 30 s (běžný „desktopový" provoz)
fio --name=randread --filename=$HOME/fio-test.bin --size=1G --rw=randread --bs=4k --direct=1 \
  --ioengine=libaio --iodepth=1 --time_based --runtime=30 2>&1 | tee "$OUT/${TS}_test-53-ssd-randread.log"

# 5.4 — úklid
rm $HOME/fio-test.bin
```

- [ ] Mezi kroky 5.1–5.3 sledovat SSD Composite v terminálu se záznamem — při ≥ 60 °C přerušit
- [ ] Po 5.4 nechat 5 min chladnout, pak ukončit záznam teplot (Ctrl+C)

Orientační rychlosti pro Samsung 990 EVO Plus 2 TB (Gen4 x4): sekvenční čtení a zápis v řádu **několika GB/s**. Přesné hodnoty z datasheetu zde neuvádím — hlavní je, že disk běží na Gen4 x4 (krok 1.3) a výsledky nejsou v řádu stovek MB/s.

### Byl SSD při instalaci nový?

**Ano.** SMART čítače (před testem, 11:14):

| Čítač | Hodnota | Výklad |
|---|---|---|
| Power On Hours | 2 | použitý disk by měl stovky až tisíce hodin |
| Power Cycles | 3 | boot instalátoru po znovuzasunutí, reboot po instalaci, dnešní start |
| Data Units Written | 15.8 GB | odpovídá instalaci Debianu (na `/` je 7.6 GB + stažené balíčky, formátování, logy) |
| Data Units Read | 29.7 GB | |
| Percentage Used | 0 % | z 1 200 TBW |
| Unsafe Shutdowns | 1 | pravděpodobně vypnutí během instalace / při znovuzasunutí SSD |

Po testu (11:44, `…-60-smartctl-po-testu.txt`): Written **17.0 GB (+1.2 GB)** = 1 GB testovací soubor + systémové zápisy; Read **174 GB (+144 GB)** = 20 s sekvenčního čtení při 7 GB/s (142 GB) + 4K test (3 GB); Power On Hours 3; ostatní beze změny, stále 0 chyb. Čítače tedy přesně sledují provoz — potvrzuje to, že jim lze věřit.

SMART čítače nelze při „repasi" vynulovat, jde tedy o spolehlivý důkaz. Souhlasí s kontrolou při převzetí (výroba 11/2025, originální balení).

### Závěr

- Hardware je v pořádku: SSD zdravý, nový, běží na plné Gen4 x4 rychlosti, v jádře žádné chyby.
- CPU chlazení funguje — při 25–50 % zátěži max. 80 °C, rychle zpět do klidu. Ventilátor je pod zátěží hlasitý (hlášeno při 25 %).
- SSD i s nesundanou fólií max. 50 °C při krátkém čtení (limit 70 °C, varování disku 81 °C). Pro delší zátěž ale fólii sundat, jak je plánováno.
