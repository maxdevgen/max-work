### 14. Česká klávesnice (17:04)

- Rozložení **US + Česká QWERTY** (`cz` varianta `qwerty`), přepínání **Alt+Shift** (`grp:alt_shift_toggle`).
- Běžící relace: `setxkbmap -layout us,cz -variant ,qwerty -option grp:alt_shift_toggle`
- Systémově (Xfce, přihlašovací obrazovka, konzole): zápis do **`/etc/default/keyboard`** přes `pkexec` (záloha `/etc/default/keyboard.bak-26-09-28`):
  ```
  XKBLAYOUT="us,cz"
  XKBVARIANT=",qwerty"
  XKBOPTIONS="grp:alt_shift_toggle"
  ```
  pak `udevadm trigger --subsystem-match=input --action=change`. Ověřeno: `localectl status` hlásí `X11 Layout: us,cz`, `X11 Variant: ,qwerty`.
  - `localectl set-x11-keymap …` nefungoval: bez terminálu nevyvolal výzvu k heslu a přes `pkexec` vrátil „Access denied"
- GNOME (vlastní nastavení): `gsettings set org.gnome.desktop.input-sources sources "[('xkb', 'us'), ('xkb', 'cz+qwerty')]"` a `xkb-options "['grp:alt_shift_toggle']"`
