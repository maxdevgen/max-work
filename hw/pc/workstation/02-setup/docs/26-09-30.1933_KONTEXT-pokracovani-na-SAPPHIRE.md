## 2. Úkol, který zbývá dokončit — ověření dual-channel

Uživatel chce **reálně ověřit**, že RAM běží v dual-channel režimu (ne jen odvodit z toho, že BIOS hlásí 64 GB a oba sloty jsou osazené).

### 2.1 Rychlé ověření — kanály podle dmidecode

```bash
sudo dmidecode -t memory | grep -E "Locator|Size|Speed|Manufacturer|Part Number"
```

Hledat, že `Locator`/`Bank Locator` ukazuje **dva různé kanály** (typicky `Channel-A-DIMM0` / `Channel-B-DIMM0`, přesný text závisí na BIOSu).

### 2.2 Reálné měření propustnosti

```bash
sudo apt install -y mbw
mbw -n 5 1024
```

Orientačně: DDR5-4800 dual-channel by měl dát řádově **desítky GB/s** (teoretické maximum ~76,8 GB/s, reálně spíš 60–70 %), jeden kanál zhruba polovina. **Nemáme "před" měření** na provizorním 8GB single-channel modulu (tehdy jsme měřili jen CPU/SSD), takže jde spíš o kontrolu rozumnosti čísla než přímé porovnání.

### 2.3 Volitelně — druhá metoda pro křížovou kontrolu

`sysbench memory --memory-block-size=1M --memory-total-size=10G run` — uživatel byl na tohle dotázaný, ale zatím neodpověděl, jestli to chce navíc.
