# Společný CPU benchmark — Dell Latitude 5510 vs. SAPPHIRE Edge AI 370 (postup)

Založeno 2026-09-28. Cíl: změřit skutečný poměr výkonu obou strojů **stejným kódem**. Dosavadní odhad 6,35× vícejádrově / 2× jednovláknově je z PassMarku ([benchmark Dell → SAPPHIRE](../../01-before.order/SAPPHIRE/SAPPHIRE_EdgeAI_370/26-09-24.1723_benchmark-Dell-vs-SAPPHIRE-odhad.md)), dřívější měření na Dellu (PowerShell) a na SAPPHIRE (`stress-ng`, [lehký test](26-09-28.1109_prvni-lehky-test-a-teploty.md)) se porovnat nedají.

## Skript

[scripts/cpu-bench.py](../scripts/cpu-bench.py) — Python, stejný na Linuxu i Windows:

| Zátěž | Co dělá | Odpovídá |
|---|---|---|
| `py` | matematika ve smyčce v čistém Pythonu | skriptování, nástroje v Pythonu |
| `zlib` | komprese dat (nativní C) | kompilace, balení, práce s daty |

- Měří **propustnost** (jednotek práce za sekundu) každých 5 s → je vidět i pokles výkonu v čase (throttling). Souhrn porovná první a poslední čtvrtinu běhu.
- Jednovláknově 30 s, vícevláknově 120 s (Dell v dřívějším testu zpomalil během ~25–90 s).
- Na Linuxu zaznamenává i teplotu CPU a nejvyšší takt jádra; na Windows jen propustnost (teplotu Dellu změříme případně zvlášť jeho [skriptem s LibreHardwareMonitor](../../../laptop/Dell.Latitude.5510/scripts/26-09-26.1645_Dell-teplota-zatez-test.ps1)).
- Výstup: `YY-MM-DD.HHMM_cpu-bench-<label>.json` (celý průběh) a `.md` (souhrnná tabulka).

**Podmínka srovnatelnosti:** stejná verze Pythonu na obou strojích (SAPPHIRE: **3.13**), zavřené aplikace na pozadí.

## Běhy

| # | Stroj | Procesy | Proč | Kdy |

## Dell (Windows)

1. Stáhnout aktuální repo (`git pull` na větvi `26-09-17.1225.hw.monitor`), aby byl skript v `C:\repos\max-work`.
2. Nainstalovat Python 3.13 (PowerShell):

   ```powershell
   winget install --id Python.Python.3.13 --exact
   ```

3. Zavřít Teams, Chrome, VS Code a další aplikace (při minulém testu běželo na pozadí ~33 % zátěže). Napájení z adaptéru, režim napájení „Nejlepší výkon".
4. Spustit (PowerShell, trvá ~6 min):

   ```powershell
   py -3.13 C:\repos\max-work\hw\pc\workstation\02-setup\scripts\cpu-bench.py --out C:\repos\max-work\hw\laptop\Dell.Latitude.5510\tests --procs 1,8 --label dell 2>&1 | Tee-Object -FilePath "C:\repos\max-work\hw\laptop\Dell.Latitude.5510\tests\$(Get-Date -Format 'yy-MM-dd.HHmm')_cpu-bench-dell.log"
   ```
