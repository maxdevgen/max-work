# NUC14 — RAM modul (Micron DDR5-4800 8GB) a kompatibilita pro test v SAPPHIRE 370

Samostatný soubor k paměti stávajícího [NUC14](./26-09-13.2245_nuc14-hardware-specs.md). Sestaveno 2026-09-25. Cíl: zdokumentovat přesnou specifikaci modulu z NUC14 a ověřit, zda ho lze na zkoušku použít v [SAPPHIRE Edge AI 370](./SAPPHIRE/SAPPHIRE_EdgeAI_370/26-09-23.2315_prehled-a-nezavisle-recenze.md).

## Specifikace modulu (potvrzeno)

Spec z part-number lookupu **souhlasí** s reálným výpisem `dmidecode` z NUC14 (stejné PN) — data jsou tedy ověřená.

| Údaj | Hodnota |
|---|---|
| Výrobce | Micron |
| Model (PN) | **MTC4C10163S1SC48BA1** |
| Typ | SO-DIMM |
| Kapacita | 8 GB (1 modul) |
| Standard | DDR5 / PC5 |
| Rychlost | 4800 MT/s |
| Klasifikace | PC5-4800B-SC0-1010-XT |
| Napětí | 1,1 V |
| Konektor | 262 pinů |
| Rank / organizace | 1Rx16 (single-rank) |
| Buffering | Unbuffered (nenárazníkový) |
| ECC | Non-ECC |

> NUC14 má **jen 1 paměťový slot** (max 32 GB), takže běží single-channel. Po vyjmutí modulu NUC14 nenaběhne, dokud se nevrátí.

## Kompatibilita se SAPPHIRE 370 (pro test) — ✅ ano

SAPPHIRE Edge AI 370 (Ryzen AI 9 HX 370) potřebuje **DDR5 SO-DIMM, non-ECC**, až 5600 MT/s, 2 sloty.

| Kritérium | NUC14 modul | SAPPHIRE potřebuje | Sedí? |
|---|---|---|---|
| Provedení | SO-DIMM, 262-pin | DDR5 SO-DIMM 262-pin | ✅ |
| Typ | DDR5 / PC5 | DDR5 | ✅ |
| Rychlost | 4800 | až 5600 → poběží na 4800 | ✅ (jen pomaleji) |
| Napětí | 1,1 V | 1,1 V | ✅ |
| ECC | Non-ECC, unbuffered | non-ECC (HX 370 ECC neumí) | ✅ |
| Profil | JEDEC (bez XMP/EXPO) | — | ✅ univerzální Intel↔AMD |
| Rank | 1Rx16 single-rank | — | ✅ funguje (levnější organizace) |

**Závěr:** modul je pro **testovací spuštění SAPPHIRE plně použitelný** — naskočí jako **single-channel 8 GB @ 4800 MT/s**. Ideální „smoke test" (ověřit boot / POST / BIOS / teploty naprázdno) ještě před příchodem cílového [Corsair 64GB kitu](./SAPPHIRE/SAPPHIRE_EdgeAI_370/RAM/26-09-24.1539_SAPPHIRE370_srovnani-RAM-vhodnost-Intel-AMD.md).

## Upozornění

1. **8 GB single-channel = jen na test**, ne na reálný provoz.
2. **NUC14 má jediný slot** → po vyjmutí modulu NUC14 neběží. Postup: vyjmout → vyzkoušet v SAPPHIRE → vrátit zpět (nebo nechat v SAPPHIRE, dokud nedorazí Corsair).
3. Nic se nepoškodí — je to standardní JEDEC DDR5, funguje na AMD i Intelu.

## Praktický scénář

Až budeš mít SAPPHIRE otevřený a osazený SSD, udělej tímhle 8GB modulem z NUC14 **první zkušební zapnutí** (boot/BIOS/teploty naprázdno). Po příchodu Corsair kitu modul vrať do NUC14.
