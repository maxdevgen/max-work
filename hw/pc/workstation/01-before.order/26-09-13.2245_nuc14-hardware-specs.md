## System

- **Model**: NUC14MNK-B2 (motherboard: NUC14MNB2)

## CPU

- **Model**: Intel(R) N250
- **Architecture**: x86_64
- 1 socket, 4 cores, 1 thread per core (no hyperthreading) — 4 logical
  CPUs total
- Clock range: 800 MHz – 3800 MHz (boost)
- Part of Intel's low-power "Alder Lake-N" / N-series line — a
  budget/efficiency-focused CPU, not a high-core-count workstation
  chip. Worth knowing when comparing against other machines: this is
  the likely ceiling on how much concurrent CPU-heavy work (video
  encoding, multiple browser instances, compilation) this machine can
  absorb before real contention shows up — already observed live this
  session (a real "Overloaded" load average of 12-14 while `ffmpeg` +
  heavy `chrome`/`obs` usage were running concurrently, on only 4
  logical CPUs).

## Memory

- **Total**: 7.4 GiB physical RAM (8 GB nominal — the difference is
  normal OS/firmware reservation, not missing hardware)
- **Swap**: 7.6 GiB configured
- Real snapshot at capture time: 5.5 GiB used, 139 MiB free, 2.7 GiB
  buff/cache, 5.6 GiB of swap already in use — a genuinely tight
  memory budget for concurrent heavy workloads (multiple browser
  processes, screen recording, several running services).
- **Detailed specs** (via `dmidecode --type memory`, real data):
  - **Type**: DDR5, 4800 MT/s, SODIMM
  - **Manufacturer**: Micron Technology (part `MTC4C10163S1SC48BA1`)
  - **Voltage**: 1.1 V
  - **Slots**: **1 of 1 populated** — this board has only a single
    memory slot (`Maximum Capacity: 32 GB`, `Number Of Devices: 1`),
    so this machine runs in **single-channel** mode, not dual-channel.
    Worth flagging specifically for a performance comparison: a
    single-channel DDR5-4800 config has roughly half the real memory
    bandwidth of an otherwise-identical dual-channel setup — a
    meaningful, real difference versus another N250/NUC14-class
    machine that happens to have two DIMMs installed, independent of
    the CPU itself being identical.

## Power / TDP (doplněno 2026-09-22, ověřeno u Intelu)

- **Intel N250 – Processor Base Power (PL1): 6 W** (zdroj: [Intel ARK](https://www.intel.com/content/www/us/en/products/sku/241637/intel-processor-n250-6m-cache-up-to-3-80-ghz/specifications.html), oficiální specifikace). Maximum Turbo Power (PL2) není u N-řady na ARK stránce samostatně uvedeno.
- Pro srovnání: to je výrazně méně než úsporná U-řada (15 W base) u MSI Cubi 5 / Acer Veriton kandidátů, natož H-řada (40–65 W) nebo desktopová K-řada (125 W+). N-řada je Intelova nejnižší výkonová/budget třída, ne součást běžné U/H/K hierarchie.
- Vysvětluje to i dřív zaznamenané chování: při souběžné zátěži (ffmpeg + OBS + Chrome, viz [teplotní test](26-09-16.2046_Nuc14.chlazeni-teplota.md)) se load average vyšplhal na 12–14 na pouhých 4 logických CPU bez hyperthreadingu – 6W/4jádrový čip má mnohem menší výkonovou rezervu než 15W/10jádrová U-řada u srovnávaných kandidátů.
