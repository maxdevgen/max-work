# Zadání pro agenta (Claude in Chrome): dohledání ASUS barebone mini-PC na Alza.cz

Vytvořeno 2026-09-22. Kontext: MSI řada na Alze postupně mizí (12M-405BEU ukončeno, 12M-001BEU jen "na objednávku" — takový status jsme se rozhodli nebrat vůbec v úvahu). Uživatel na Alze narazil na výrazně širší nabídku značky **ASUS** a chce se přesunout tímhle směrem.

## Kritéria hledaného produktu

1. **Výrobce: ASUS**
2. **Typ: Barebone** — **bez RAM** ("RAM 0 GB") a **bez disku** ("SSD 0 GB" / "bez úložiště")
3. Kategorie: **mini PC / NUC**, ale i příbuzné řady jako **ExpertCenter** (typ skříně "Desktop", ne jen Mini ITX) — nebuď příliš úzký na jednu kategorii, ASUS má víc produktových řad (NUC, ExpertCenter, ROG NUC), zajímá nás vše, co je barebone.
4. **Nezavrhuj podle CPU třídy předem** — zaznamenej CPU u každého nalezeného produktu (model + generace), i H-řadu i U-řadu, ať má uživatel data pro vlastní rozhodnutí.
5. **⚠ Preferuj ověřenou generaci, ne nejnovější.** Nejnovější Intel generace (Core Ultra Series 3 "Panther Lake", uvedeno leden 2026) je zatím moc čerstvá — chybí nezávislé recenze, nejasná reálná dostupnost U-řady, velký rozptyl mezi marketingovými sliby a prvními uniklými testy. **Preferovaná generace: Core Ultra Series 2 (Lunar Lake / Arrow Lake, podzim 2024)** nebo starší (Core Ultra Series 1 "Meteor Lake", 13. gen, 12. gen) — u těch už jsou ověřené nezávislé recenze. Pokud narazíš na Series 3 (Panther Lake) produkt, zaznamenej ho, ale označ jako "nejnovější generace – nezávisle neověřeno" a nedávej ho mezi hlavní doporučení.

## Jak postupovat

1. Otevři **alza.cz**.
2. Vyhledej **"ASUS NUC"**, **"ASUS ExpertCenter"**, a obecně **"ASUS mini PC barebone"** — zkus víc dotazů, ať se nic nevynechá.
3. U produktů označených **"X varianty"** (jako u NUC 14 Pro a NUC 15 Pro výše) **rozklikni a vypiš každou variantu zvlášť** (liší se obvykle CPU/barvou/cenou) — nespokoj se jen se souhrnnou kartou.
4. Vyfiltruj jen ty, co jsou **bez RAM a bez disku** (barebone) — přeskoč kompletní PC s předinstalovanou pamětí/diskem.
5. U každého nalezeného produktu zaznamenej:

| Parametr | Co zjistit |
|---|---|
| Přesný název/SKU | jak ho Alza uvádí |
| URL produktové stránky | |
| **Dostupnost (doslovně)** | "Skladem > X ks" / "Naskladníme do X dnů" / "Na objednávku – termín upřesníme" / "Prodej skončil" — přesné znění |
| Cena | aktuální cena v Kč vč. slevy |
| Procesor (přesné označení + generace) | např. "Intel Core Ultra 5 125H" |
| Max. RAM a typ (DDR4/DDR5) | |
| Rozměry skříně, pokud uvedeno | |
| Video výstupy / Thunderbolt | |
| Hodnocení (počet recenzí) | |

6. **Vyřaď produkty se statusem "Na objednávku – termín upřesníme"** ze seznamu hlavních kandidátů, ale zapiš je do zvláštní sekce "Nejisté" — nechceme opakovat scénář MSI 405BEU/001BEU.

## Kontext projektu (pro orientaci, není nutné dál zkoumat)

- Hledáme náhradu za 24/7 pracovní mini-PC (Claude Code, Docker, běžná kompilace).
- Dosavadní priorita byla úsporná U-řada CPU (~15W) kvůli tichému provozu, ale uživatel teď zvažuje otevřít výběr i ASUS řadám s H-řadou (~40-65W) — nerozhoduj o tom sám, jen data přines, rozhodnutí padne až po zhodnocení nabídky.
- Cílová RAM konfigurace: 64 GB (dokupuje se zvlášť k barebonu).
