## 2. How DisplayLink works (why it's special)

A normal external monitor is driven directly by the GPU over HDMI/DisplayPort. A DisplayLink dock
is different: there is no video cable from the GPU to the dock. Instead:

1. An **indirect display driver** presents a virtual monitor to Windows.
2. A **user-mode app (DisplayLink Manager)** continuously captures and compresses that virtual
   desktop and streams it over USB to the dock.
3. The dock's DisplayLink chip decompresses the stream and outputs it to the physical monitor.

Consequence: **the DisplayLink Manager app must be installed and running** or there is no video —
even though the dock, its USB hub, Ethernet and audio all work fine without it. This rendering app
is **not** delivered by Windows Update (Microsoft only ships the low-level USB component), so it
must be installed by hand.

## 3. Daily use

- Plug the single USB cable from the dock into the laptop. Hub, Ethernet and audio come up automatically.
- **DisplayLink Manager** must be running (tray icon). Set it to start with Windows so the dock
  display appears automatically at logon.
- Arrange / extend screens: `Win + P` -> **Extend**, or Settings -> System -> Display.
- The dock display behaves like any other extended monitor once the software is running.

## 5. Troubleshooting

| Symptom | Action |
|---|---|
| Dock display still dark after install | Confirm `DisplayLinkManager.exe` is running; launch DisplayLink Manager manually |
| Display works but drops after sleep | Set DisplayLink Manager to start with Windows; re-run `Win + P` -> Extend |
| Ethernet/audio work but no video | Expected without the Manager app — that is the DisplayLink video component |
| Wrong resolution | Set it in DisplayLink Manager or Windows Display settings |

Note: a `Win + P` sleep/wake cycle (the fix for a native monitor losing signal) will **not** fix a
missing DisplayLink stack — that is a software-install problem, not a signal problem.

## 6. Resolution & refresh-rate compatibility (PL2792QN)

Short answer: **resolution — yes; full refresh rate — no.** The dock drives the monitor at its
full native resolution (2560 x 1440 QHD) but **cannot reach the monitor's high refresh rate**. It
caps QHD at roughly 50-60 Hz.

### 6.1 What the monitor needs

| Property | Value |
|---|---|
| Native resolution | 2560 x 1440 (QHD) |
| Native refresh | 75 Hz or 100 Hz, depending on exact PL2792QN sub-variant (e.g. XUB2792QSN ~75 Hz; newer XUB2792QSU-W6 100 Hz) — in all cases above 60 Hz |

### 6.2 What the D3100 dock can deliver

The D3100 uses the DisplayLink DL-3900 chip and does **not** support DP 1.2 / MST. Per-port maximums
(with a single monitor on the dock, so it gets the full per-port budget):

| Dock output | Max resolution | Max refresh at that resolution |
|---|---|---|
| DisplayPort | 3840 x 2160 (4K) | 30 Hz |
| DisplayPort at QHD | 2560 x 1440 | ~50-60 Hz |
| HDMI | 2560 x 1440 | 50 Hz |

### 6.3 Verdict

| Requirement | Supported by dock? | Notes |
|---|---|---|
| 2560 x 1440 resolution | **Yes** | Full native sharpness on either dock port |
| 75 Hz / 100 Hz refresh | **No** | Dock caps QHD at ~50 Hz (HDMI) to ~60 Hz (DP); high refresh is lost through DisplayLink |

So through this dock you get a crisp full-resolution picture, but the monitor runs at a lower refresh
rate than it is capable of.

### 6.4 Recommendations

- For the best result **via the dock**, connect the PL2792QN to the dock's **DisplayPort** output
  (not HDMI) — QHD at up to ~60 Hz instead of 50 Hz.
- To get the monitor's **full native refresh (75/100 Hz)**, connect it **directly to the laptop's
  GPU** (HDMI/DP), not through the DisplayLink dock. DisplayLink cannot deliver high refresh at QHD.
- DisplayLink is software-compressed video over USB — excellent for office/productivity; fast motion
  or gaming may show mild compression artifacts and higher CPU use.

### 6.5 How to confirm the actual mode after install

- Settings -> System -> Display -> Advanced display -> select the dock monitor -> check the
  **refresh-rate** dropdown for the modes the dock actually offers.
- Confirm the monitor's exact rated max refresh from its rating label / OSD (to know whether the
  panel is the 75 Hz or 100 Hz variant).

## 7. Diagnostic evidence (commands + results)

Run in PowerShell. Key commands used to reach the conclusions above.

    Get-PnpDevice | Where-Object { $_.FriendlyName -like "*DisplayLink*" -or $_.InstanceId -like "*VID_17E9*" }
    Get-Process DisplayLinkManager -ErrorAction SilentlyContinue   # count = 0
    Get-ItemProperty "HKLM:\SOFTWARE\...\Uninstall\*" | Where-Object DisplayName -like "*DisplayLink*"   # none
