# Dell Latitude 5510 — diagnostika vytížení CPU („nic nedělám, a CPU >50 %")

Měřeno 2026-09-25 přímo na stroji [Dell Latitude 5510](./26-09-13.2243_Dell_Latitude5510.current-machine.md) (i5-10310U, 4 jádra / 8 vláken) přes Claude Code session. Dotaz: PC zdánlivě nečinné, ale CPU >50 % — proč?

## Závěr: není to zaseknutý proces

CPU osciluje **31–59 % (průměr ~40 %)**, ne trvale zaseknutých 50 %. Je to **součet několika reálně běžících věcí** + slabý CPU, ne jeden runaway proces.

## Naměřené vytížení procesů (živé CPU)

| Proces | % jednoho jádra | Co to je |
|---|---|---|
| **obs64** (OBS Studio) | ~19 %, **trvale** | běží a průběžně **renderuje náhled zdrojů** → žere CPU i „nečinně" |
| **code** (VS Code) | špička ~99 %, pak 0 % | jazykové servery / indexování / file watcher — **jednorázový záblesk**, ne trvalý |
| **taskmgr** (Správce úloh) | ~19 % | otevřený Správce úloh — **sledování CPU samo přidává** ~2–3 % |
| **msmpeng** (Defender) | ~8 % | skenování na pozadí (dočasné) |
| **audiodg** | ~11 % | zpracování zvuku (něco hraje) |
| urban-vpn, dwm, svchost | ~8 % | běžné pozadí |
| **wmiprvse** | ~23 % | ⚠ z velké části **způsobeno měřením** (WMI dotazy) — po dokončení zmizí |

## Interpretace

„Nic nedělám" ve skutečnosti = **OBS běží + otevřený Správce úloh + Defender skenuje + VS Code jazykové servery + zvuk + pozadí**. Žádný z nich není chyba — jen se to na **slabém i5-10310U (4 jádra)** rychle nasčítá k ~50 %.

**Pointa projektu:** stejná sada aplikací na pozadí by na [SAPPHIRE 370](../pc/workstation/SAPPHIRE/SAPPHIRE_EdgeAI_370/26-09-23.2315_prehled-a-nezavisle-recenze.md) dělala ~5–8 % místo ~50 % (6,35× víc výkonu). Dell je na hraně už jen s „pozadím" — souvisí s [benchmarkem Dell→SAPPHIRE](../pc/workstation/SAPPHIRE/SAPPHIRE_EdgeAI_370/26-09-24.1723_benchmark-Dell-vs-SAPPHIRE-odhad.md).

## Jak snížit vytížení (hned)

1. **Zavřít OBS**, když nestreamuješ — největší trvalý žrout „nicnedělání".
2. **Zavřít Správce úloh** — ubyde jeho i měřicí režie.
3. VS Code záblesky jsou normální (jazykové servery); kdyby vadily, vypnout těžká rozšíření.
4. Defender skenování doběhne samo.

## Metodika

- Živé CPU procesů: `Get-Counter '\Process(*)\% Processor Time'` (% jednoho jádra; /8 = podíl na systému).
- Celkové CPU: `Get-Counter '\Processor(_Total)\% Processor Time'`, opakované vzorky.
- ⚠ Měření samo (WMI/Get-Counter) přidává několik % (wmiprvse) — reálný klidový stav bez měření a bez OBS/taskmgr by byl nižší.
